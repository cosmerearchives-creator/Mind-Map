# Pointer scopes, dialogs and moving Stickies

Ctrl+wheel zooms the surface under the pointer: a Board canvas, the home viewport or the image-region editor. Over UI controls it scales the UI. The Windows host disables automatic WebView browser zoom and accepts bounded UI zoom requests from the trusted main page. Page-only environments use a CSS zoom fallback.

The home page clips project tiles to a transform-based viewport instead of increasing a scrolling document's width/height. Drag empty space or middle-drag to pan; the heading, search and actions remain fixed. Wheel/Shift-wheel also pan, Ctrl-wheel zooms, and Fit projects/Reset view recover offscreen content. The current home view is a device-local preference; tile positions remain Board metadata for backup/sync.

Dialogs make the background app inert, focus inside the dialog, contain keyboard/clipboard bubbling, and disable background shortcut handlers. Text inputs keep normal editing shortcuts. Escape invokes the active dialog's Cancel/Close action when available. Image point editing handles its own Undo/Redo before events leave the dialog. Native Alt menus also stay hidden during dialogs.

The image-region viewport fits the original image initially and supports 20%–1200% of that fitted view. Zoom buttons, pointer-centered Ctrl-wheel and two-finger pinch change only the view transform. Middle mouse or the Hand tool pans. Two-finger navigation rolls back the tentative first-finger point so a pinch does not add an unwanted vertex. Ctrl+Z and Ctrl+Y/Ctrl+Shift+Z undo/redo points; regular drawn shapes and freehand strokes are local undo steps too. Region geometry is unchanged by zoom/pan. Hover and activation use mathematical point-in-shape tests, separate from SVG stroke hit areas.

Ctrl+X is a pending pickup. Selected cards and Collection/image-region descendants are copied to the clipboard with a session token; the source is dimmed but remains safely saved until paste succeeds. In the same session, Ctrl+V moves the originals to the active Board, or into a selected Collection. Nested Board IDs stay intact, Collections retain children, image targets retain owners, and internal connections move together. Cross-Board connections to unselected source cards are removed because connections are Board-local. A cycle, changed source selection, conflicting destination IDs or storage failure leaves the source untouched. Escape or another copy cancels pickup. After restart, or in another app session/device, the clipboard payload is treated as a normal copy; no source data was deleted. Repeated paste after a successful move makes a normal independent copy. Moves are one undoable workspace action.
