# Workspace interaction update

Card editors have independently scrolling content and a solid footer flush with the dialog's bottom edge. Delete, Cancel and Save remain; Connect and Unlink are removed from this editor. Existing connection handles and saved connections remain available. On computers and landscape screens, the corner grip resizes the editor without rebuilding its fields. The focused grip also supports arrow keys. Portrait phones keep their compact editor.

Collection membership changes on drop rather than constraining the pointer during a drag. Free Collections retain the dropped position within their existing header/sizing rules. Arranged Collections insert the dragged Sticky at its new vertical position and shift siblings to make room. Dropping outside a Collection detaches the Sticky; dropping into another Collection transfers it. The Sticky center determines the destination, with the top header excluded. Collections cannot be dropped into themselves or their descendants. IDs, note bodies and connections are retained. Arranged Collections expand enough to show their arranged contents, up to the existing frame limit.

Board actions now opens one menu containing Tags, Import tags, Back, Unsorted, Paste and Board shortcut. Interface labels cannot be selected while panning; input and rich-editor text remain selectable. Canvas tips have a dismiss button, remembered locally for this device. Restore tips through Windows Alt > View > Canvas tips, or through Board actions > Show canvas tips on either platform. Tip visibility is a device preference and does not modify synced Board data.

Edit Canvas provides Pen, Eraser and Hand. Hand pans with a pointer; holding the middle mouse button temporarily pans while Pen/Eraser stays selected. Two-finger touch movement pans, cancelling the tentative first-finger stroke so it leaves no accidental mark. Pending stroke coordinates live in Board space, and view changes move the drawing together with the Board. Finish includes strokes beyond the current viewport. Undo/redo affect strokes, not viewport movement. Cancel adds no image. Raster export is bounded to a 4096-pixel longest side and 16 megapixels; larger drawings are downsampled for memory safety. Existing image/frame limits still apply. Panning is supported while drawing; pinch zoom is not added to drawing mode in this update.

The Windows updater previously reused one temporary directory and the same installer/partial filenames for each version. An existing locked installer or partial file could prevent a retry. Each new attempt now owns a unique directory, first under the current user's local app data and then under temporary storage if the first location is unavailable. Finalizing never overwrites a prior installer. Downloads must match the advertised length and have a Windows executable header. Failure messages distinguish preparation, download, validation and launch; a diagnostic log is written under the user's Archives of Arcanum local app data folder when possible. A launch failure keeps the completed installer available for manual launch. Board storage and credentials are not part of these changes.

The screenshot alone does not establish which operation caused the original access-denied error. Unique-path handling removes a reproducible collision risk; system policy, antivirus or other external restrictions cannot be established by these tests. The installed older updater cannot gain this fix until the new version is installed, potentially requiring a manual download once.

Validation includes shared snapshot/property suites, two-device automatic sync and recovery tests, existing Sticky/canvas/rich-text/clipboard browser tests, workspace-interactions.cjs and drawing-pan.cjs. Windows CI also runs the updater console tests against unique attempts, a locked prior installer, unavailable primary directories, invalid/truncated downloads, no-overwrite behavior and partial-file cleanup before building the installer. Physical-device rotation/keyboard behavior, native Alt menu interaction and the full updater installation flow require device checks.
