# Image regions and home layout

Edit an Image Sticky (double-click a raw image) and choose Clickable image regions. Pick rectangle/square, ellipse/circle, triangle, rounded rectangle, diamond, pentagon, hexagon, star, arrow, freehand or point outline. Drag to draw; Shift constrains rectangles/ellipses to square/circle in screen pixels. Point outlines use individual clicks and Close outline. Create Sticky for selection opens the existing creation menu, with Nested Board checked and a blank title. Cancel leaves the workspace unchanged.

Regions use normalized image coordinates. The overlay uses the same image dimensions and offsets as the displayed image, so scaling/repositioning retains the hit area and the frame clips both together. The transparent hit area has no permanent border by default. The optional border follows the shape with constant screen stroke width; hovering/focusing provides a temporary outline. Click or Enter/Space activates a region. Nested Boards open normally, Ctrl-click uses another tab; other Sticky kinds open their existing editor.

The manager lists regions for content editing, redrawing, border toggling and detaching to the canvas. Targets are ordinary Board cards with an `imageRegion` owner ID and geometry. Usual nested ownership, sync and deletion rules remain intact. Targets render through the owning image instead of as extra canvas rectangles. Copy closure includes them and remaps owner IDs and nested Board IDs. Duplicate-Board consolidation also remaps image owners. Removing the image detaches surviving targets instead of deleting their content; Undo restores ownership and geometry.

The home screen is a positive-coordinate freeform surface using the landing page's existing scroll area. Tiles keep previews and click navigation. Drag to move, or focus and press Alt plus arrows; positions are Board metadata, so backup and sync retain them. New tiles choose unoccupied default positions. Select boards temporarily disables dragging for bulk selection. Heading, search, import and creation controls remain separate. The home screen does not gain drawing, connections or Sticky editing.

Canvas zoom ranges from 5% to 300%. Scroll deltas pan in screen pixels, Shift redirects vertical wheel movement horizontally, Ctrl/Command zooms around the pointer. Editors, menus and toolbars keep their normal scrolling. Connected components arrange into dimension-aware balanced rows separated by 180 board units. Collections move as a unit with their children. Manual junction positions reset so existing connection routing follows the new positions.

Introduction migration recognizes the old starter Board only when at least two known original tip bodies remain. It renames that Board, updates only matching original bodies, preserves modified cards, adds missing new tips below existing cards, and marks the migration complete. Unrecognized/user-customized Boards are not rewritten.
