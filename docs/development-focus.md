# Current development focus

Windows and Android publish coordinated releases. Android app-to-app sharing resumed in 0.14.1 at the project owner's request. Preserve package identity, signing certificates, existing storage and cloud protocols on both platforms; core research functionality remains offline with no account requirement.

Every official release requires successful builds from the exact current main commit. The Windows installer and signed Android APK keep the existing updater asset names. New .arcanum transfer limits do not apply to workspace backups or sync. See [package protocol](arcanum-package-v1.md).
